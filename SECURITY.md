# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public issues. Use GitHub's private vulnerability reporting for this repository, if enabled, or contact the maintainer privately through the contact information on the maintainer's GitHub profile.

Include the affected version, macOS version, reproduction steps, and impact. Avoid attaching logs containing device identifiers or other personal data.

## Supported versions

Security fixes are intended for the latest published release. This app is distributed outside the Mac App Store and relies on undocumented `bluetoothd` log output for its primary feature.
